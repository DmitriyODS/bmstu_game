# Спецификация: Бауманка.Квиз

## Обзор продукта

**Бауманка.Квиз** — веб-приложение для проведения интерактивных командных квизов в реальном времени.

Три типа экранов, работающих синхронно через WebSockets:
1. **Админ-панель** — для организатора
2. **Экран презентации** — проецируется на большой экран (TV/проектор)
3. **Экран участника** — смартфон каждой команды

---

## Роли

| Роль | Доступ | Авторизация |
|------|--------|-------------|
| Организатор | Полный доступ к админ-панели | Логин + пароль |
| Судья | Только раздел проверки ответов | Логин + пароль |
| Участник | Экран участника | Сессия по QR-ссылке |
| Зритель | Только экран презентации | Без авторизации |

- Логин/пароль по умолчанию: `admin` / `admin`
- В настройках — возможность сменить логин и пароль
- Судьи создаются организатором (логин + пароль)

## Модели данных

### Quiz (Квиз)
- `id` UUID PK
- `title` string — название
- `description` text — описание (опционально)
- `is_active` boolean — только один квиз активен одновременно
- `status` enum: `draft` | `active` | `finished`
- `created_at` timestamp

### Tour (Тур)
- `id` UUID PK
- `quiz_id` FK → Quiz
- `title` string — название тура
- `order` int — порядковый номер
- `splash_image` string — путь к картинке заставки тура (опционально)

### Question (Вопрос)
- `id` UUID PK
- `tour_id` FK → Tour
- `order` int — порядок внутри тура
- `question_type` enum: `text` | `text_image` | `image_only` | `audio`
- `answer_type` enum: `single_choice` | `multiple_choice` | `short_text` | `long_text` | `matching`
- `text` text — текст вопроса (null для `image_only`)
- `image_path` string — путь к картинке (для `text_image`, `image_only`)
- `audio_path` string — путь к аудио (для `audio`)
- `time_seconds` int — время на ответ в секундах
- `points` int — баллов за верный ответ (по умолчанию 1)
- `auto_check` boolean — автоматическая проверка (только для `single_choice`, `multiple_choice`)
- `correct_answer` text — верный ответ (для авто-проверки)
- `sound_start_path` string — звук при старте
- `sound_mid_path` string — звук в середине (настраиваемое время)
- `sound_mid_seconds` int — за сколько секунд до конца играет средний звук
- `sound_end_path` string — звук по окончании

### AnswerOption (Варианты ответа)
- `id` UUID PK
- `question_id` FK → Question
- `text` string
- `is_correct` boolean
- `order` int

### MatchingItem (Пары для сопоставления)
- `id` UUID PK
- `question_id` FK → Question
- `left_text` string
- `right_text` string
- `order` int

### Team (Команда)
- `id` UUID PK
- `quiz_id` FK → Quiz
- `name` string
- `session_token` string unique — для идентификации участника
- `registered_at` timestamp

### TeamAnswer (Ответ команды)
- `id` UUID PK
- `team_id` FK → Team
- `question_id` FK → Question
- `answer_text` text — для текстовых ответов
- `selected_options` JSON array — для choice-ответов
- `matching_pairs` JSON — для сопоставления `[{"left_id": ..., "right_id": ...}]`
- `submitted_at` timestamp
- `is_correct` boolean | null — null = не проверен
- `score` int — начисленные баллы
- `auto_checked` boolean — была ли применена авто-проверка
- `checked_by` UUID FK → User | null — кто проверяет прямо сейчас (для Tinder-режима)
- `checked_by_at` timestamp — когда взял на проверку (для таймаута блокировки)

### User (Пользователи системы)
- `id` UUID PK
- `username` string unique
- `password_hash` string
- `role` enum: `admin` | `judge`

### GameState (Текущее состояние игры)
- `id` UUID PK (single row)
- `quiz_id` FK → Quiz
- `current_screen` enum: `splash` | `registration` | `teams` | `tour_splash` | `question` | `question_answer` | `waiting` | `tour_results` | `game_results`
- `current_tour_id` FK → Tour | null
- `current_question_id` FK → Question | null
- `timer_started_at` timestamp | null
- `timer_seconds` int | null
- `registration_open` boolean

## Конструктор квиза

### Структура
- Квиз → Туры → Вопросы (дерево)
- Минимум 1 тур обязателен
- Порядок туров и вопросов перетаскиванием (drag & drop)

### Типы вопросов (question_type)
| Тип | Описание |
|-----|----------|
| `text` | Только текст |
| `text_image` | Текст + картинка |
| `image_only` | Только большая картинка без текста |
| `audio` | Аудио файл + текст вопроса |

### Типы ответов (answer_type)
| Тип | Описание | Авто-проверка |
|-----|----------|---------------|
| `single_choice` | Выбор одного варианта | Да |
| `multiple_choice` | Выбор нескольких вариантов | Да |
| `short_text` | Текстовое поле короткое (≤255 символов) | Нет |
| `long_text` | Текстовое поле длинное | Нет |
| `matching` | Сопоставить два столбца | Нет |

### Настройки вопроса
- Время на ответ (секунды)
- Баллы за верный ответ
- Варианты ответов (для choice-типов) с отметкой правильных
- Пары для сопоставления (для matching)
- Три звуковых события:
  - Старт — звук при запуске таймера
  - Предупреждение — звук за N секунд до конца (N задаётся)
  - Конец — звук по истечении времени
  - Загружаемые аудиофайлы (mp3/wav/ogg)

## Экраны (GameState.current_screen)

### `splash` — Заставка квиза
- **Презентация**: Название квиза, опционально логотип/фон
- **Участник**: Название квиза, "Ожидайте начала..."

### `registration` — Регистрация команд
- **Презентация**: QR-код для регистрации + URL + список зарегистрированных команд в реальном времени
- **Участник (новый)**: Форма ввода названия команды → сохранить
- **Участник (зарегистрирован, регистрация открыта)**: Название команды + кнопка "Изменить название"
- **Участник (зарегистрирован, регистрация закрыта)**: Название команды, "Ожидайте начала игры"
- **Управление**: кнопки "Показать команды отдельно" / "Закрыть регистрацию"

### `teams` — Экран всех команд
- **Презентация**: Карточки всех зарегистрированных команд

### `tour_splash` — Заставка тура
- **Презентация**: Название тура, опционально картинка
- **Участник**: Название тура, "Готовьтесь!"

### `question` — Вопрос + таймер
- **Презентация**:
  - Текст вопроса (или картинка)
  - Аудиоплеер (для audio-типа, автовоспроизведение)
  - Варианты ответов (для choice-типов)
  - Обратный отсчёт таймера (крупно)
- **Участник (во время таймера)**:
  - Варианты для выбора / текстовое поле / интерфейс сопоставления
  - Таймер (обратный отсчёт синхронизирован с сервером)
  - Кнопка отправить (для текстовых)
  - После submit — "Ответ принят", но можно изменить пока таймер идёт
- **Участник (после таймера)**: "Время вышло. Ответы не принимаются."

### `question_answer` — Вопрос с верным ответом
- **Презентация**: Вопрос + выделенный верный ответ
- **Участник**: "Правильный ответ: ..."

### `waiting` — Экран ожидания
- **Презентация**: "Ожидайте..." (кастомизируемый текст опционально)
- **Участник**: "Ожидайте следующего вопроса..."

### `tour_results` — Итоги тура
- **Презентация**: Таблица результатов по текущему туру (команда → баллы за тур)
- **Участник**: Место команды в туре + баллы

### `game_results` — Итоги игры
- **Презентация**: Финальная таблица результатов (команда → суммарные баллы)
- **Участник**: Итоговое место + баллы

## Панель управления квизом

Навигация:
- Дерево туров/вопросов (клик → переход к вопросу)
- Стрелки "Назад" / "Далее" для последовательного перехода
- Кнопки для смены экрана

Управление экранами:
```
[Заставка] [Регистрация] [Команды] [Ожидание]
[Тур: выбор из списка] → [Заставка тура]
[Вопрос: X из Y] → [Показать] [Запустить таймер] [Показать ответ]
[Итоги тура] [Итоги игры]
```

Управление таймером:
- Запустить (только после показа вопроса)
- Пауза / Возобновить
- Сброс
- Таймер отображается в панели управления тоже

## Раздел проверки ответов

### Режим Tinder (карточки)
- Судья видит одну карточку за раз
- На карточке:
  - Название команды
  - Текст вопроса (кратко)
  - Ответ участника
  - Правильный ответ (внизу карточки)
  - Кнопки: **Верно** (зелёная) / **Неверно** (красная)
  - Поле для ввода кастомного балла (целое число, по умолчанию = points вопроса / 0)
- После нажатия карточка исчезает → следующая
- Каждый ответ блокируется на одного судью (`checked_by`) — другие его не видят
- Если судья закрыл браузер — блокировка снимается через 60 секунд

### Режим таблицы
- Строки: команды
- Столбцы: вопросы текущего тура (или выбранного)
- В ячейке: ответ + статус (✓/✗/?) + балл
- Клик на ячейку → модалка с деталями и возможностью изменить оценку
- Фильтр: показать только непроверенные

### Переключение режимов
- Тоггл "Карточки / Таблица" в шапке раздела проверки
- Режим сохраняется в localStorage

### Фильтрация
- По туру
- По вопросу
- Только непроверенные
- Все

## Real-time события (WebSocket)

### Сервер → Клиенты

| Событие | Данные | Получатели |
|---------|--------|------------|
| `screen_changed` | `{screen, data}` | Все |
| `registration_opened` | — | Все |
| `registration_closed` | — | Все |
| `team_registered` | `{team_id, name}` | Презентация, Админ |
| `team_name_updated` | `{team_id, name}` | Презентация, Админ |
| `question_shown` | `{question_id, question_data}` | Все |
| `timer_started` | `{seconds, started_at}` | Все |
| `timer_tick` | `{remaining}` | Все |
| `timer_paused` | `{remaining}` | Все |
| `timer_stopped` | — | Все |
| `answer_submitted` | `{team_id}` | Админ (счётчик) |
| `answer_checked` | `{answer_id, is_correct, score}` | Судьи |
| `scores_updated` | `{scores: [{team_id, score}]}` | Все |

### Клиент → Сервер

| Событие | Данные | Источник |
|---------|--------|----------|
| `change_screen` | `{screen, ...params}` | Админ |
| `start_timer` | `{question_id}` | Админ |
| `pause_timer` | — | Админ |
| `submit_answer` | `{question_id, answer}` | Участник |
| `check_answer` | `{answer_id, is_correct, score}` | Судья |
| `request_next_card` | — | Судья |

- Ручное создание команд организатором (как альтернатива QR-регистрации)
- Поля: название команды
- Команды привязаны к конкретному квизу

## Экспорт статистики (Excel)

Файл `.xlsx` через openpyxl, кнопка в админ-панели.

Листы:
1. **Итоги игры** — команда, суммарный балл, место
2. **По турам** — команда × тур = баллы за тур
3. **По вопросам** — команда × вопрос = ответ + балл + верно/нет
4. **Детали ответов** — все ответы с временными метками, кто проверял

## QR-код и ссылка участника

- URL вида: `/play/{quiz_id}` или `/play` (если квиз активен — один)
- QR генерируется на сервере через библиотеку `qrcode`
- Отображается на экране презентации в режиме регистрации
- Участник переходит → видит форму регистрации команды
- После регистрации сессия сохраняется в cookie (`session_token`)
- При повторном заходе — сессия восстанавливается автоматически

## Маршруты приложения

```
GET  /                          → редирект на /admin или /login
GET  /login                     → форма входа
POST /login                     → авторизация
GET  /logout                    → выход

# Участник
GET  /play                      → экран участника (активный квиз)
GET  /play/<quiz_id>            → экран участника (конкретный квиз)
POST /play/register             → регистрация команды

# Презентация
GET  /screen                    → экран презентации

# Админ
GET  /admin                     → дашборд
GET  /admin/quizzes             → список квизов
GET  /admin/quizzes/new         → создать квиз
GET  /admin/quizzes/<id>/edit   → конструктор квиза
GET  /admin/quizzes/<id>/control → панель управления
GET  /admin/judge               → панель проверки ответов
GET  /admin/settings            → настройки
GET  /admin/export/<quiz_id>    → скачать Excel

# API (AJAX)
POST /api/upload                → загрузка файла
GET  /api/qr/<quiz_id>          → QR-код
```

## Приоритеты разработки

1. **Инфраструктура**: Docker, БД, базовый Flask, авторизация
2. **Конструктор квиза**: создание квиза, туров, вопросов всех типов
3. **Регистрация команд**: QR, экран участника, экран презентации
4. **Проведение игры**: управление экранами, таймер, SocketIO
5. **Ответы участников**: все типы ответов, submit, блокировка после времени
6. **Проверка ответов**: Tinder-режим + таблица
7. **Баллы и результаты**: подсчёт, экраны итогов
8. **Экспорт Excel**
9. **Конструктор команд** (ручное создание)
10. **Настройки** (смена пароля, судьи)
